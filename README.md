# JSTQB AL TM 学習支援Webアプリケーション

JSTQB Advanced Level テストマネージャ（AL TM）合格に向け、基礎（FL）の定着から実務・マネジメント判断（AL TM: K2〜K4）までを、「見る（読む）」「解く」「聴く（聞き流し）」の3軸で網羅的に学習できるWebアプリケーションです。

## 主な機能

1. **スピード一問一答モード (`/practice/quick`)**
   - 用語定義、基本概念（K1/K2）に特化。
   - タップで瞬時に正誤判定と要約解説を表示。
   - スキマ時間向けに「5問 / 10問 / 全問」の切り替え、ブックマーク、シラバスインライン表示。

2. **シナリオ文章題モード (`/practice/scenario` / `/practice/scenario/[id]`)**
   - 左右2分割スプリットビュー:
     - 左ペイン: 前提シナリオ、プロジェクト制約、ステークホルダー構成、不具合密度テーブル等の長文を常時参照可能。
     - 右ペイン: 設問・選択肢群。「シラバス根拠を表示」ボタンで右側からシラバス該当節をスライドオーバーレイ表示。
   - 大問形式に準拠（1つの共通シナリオに複数のK3/K4設問が連動）。

3. **本番模試モード (`/practice/mock`)**
   - 本番試験（AL TM: 65問・180分・合格ライン65%）およびクイック模試（15問・45分）のシミュレーション。
   - 制限時間タイマー、全問ナビゲーターパレット、「後で見直す」フラグ機能。
   - 終了後の合否判定（65%基準）、スコアカード、紙吹雪演出、全問レビュー。

4. **シラバス参照ビューア & 聞き流しプレイヤー (`/syllabus`)**
   - 階層型目次ツリー（章・節・項）とMarkdown本文レンダリング。
   - 重要用語ハイライト、Kレベルタグ表示、インライン検索。
   - Web Speech APIによるTTS連続再生（0.8x〜2.0x速度調整、15秒送り/戻し相当の段落スキップ）。
   - 音声再生中の段落を黄色ハイライトし、自動スクロール追従。

5. **学習分析ダッシュボード (`/dashboard`)**
   - 総合正答率、累計解答数、合格基準シミュレーション。
   - 認知レベル別（K1/K2/K3/K4）の習熟度プログレス。
   - シラバス章別（第1章〜第7章）の正答率バー。
   - 要復習リスト（直近で間違えた問題、ブックマークした問題への直行リンク）。

6. **シラバスデータ同期バッチ (`/sync`)**
   - `syllabus/` ディレクトリ内のPDF（AL TM, FL, AL TA）の検知・パース状態の確認。
   - 問題マスタJSONのエクスポート・インポート機能。

## 開発・起動手順

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# 型チェック
npm run typecheck

# プロダクションビルド
npm run build
npm start
```
